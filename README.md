# Белое Безмолвие: Безумный Дед 🌅

**Одна ночь на станции Пристань-Тихая. Зима 1917. Дожить до рассвета.**

Bullet-heaven в каноне проекта: дед слегка с грибами, лес лезет со всех
сторон, но теперь каждое решение — твоё.

## Что изменилось в v2.1 (после «тупой игры»)

Диагноз v2.0: петля работала, но **решений не было** — всё происходило
само, без участия игрока. v2.1 добавляет глубину и возвращает канон v1:

- **Лодошка бьёт по направлению хода** — наводка движением,站位 решает
- **Волк приседает перед рывком** — читай телеграф, отходи вбок
- **Ворона замирает и бьёт пике в отмеченную точку** — уходи с метки
- **Грибы гаснут** — жадность = риск; побежал за дальним, потерял время
- **Золотой гриб — обманка**: схватишь — лес проснётся
- **Переброс карточек [R]** — один раз за выбор
- **Рассвет вместо тарелки**: 10:00 ночи → небо золотеет → победа
- **Осада после 9:00** — финальное испытание перед рассветом
- Атмосфера: полярное сияние, вой издалека, колокол, ветер-эмбиент

## Забег

- **3:00, 6:30, 9:00** — старшие леса (боссы): Вожак стаи, Медведь-шатун,
  Атаман дезертиров
- 👑 Старшие в толпе (синее пламя) оставляют свёртки и большие грибы
- Приход 🍄 → **[G] Грибной Залп**: 5 секунд безумия
- 6 оружий: лодошка, дубина-бумеранг, лучина-веер, кот Барсик,
  грибная аура, вантуз + скрытые эволюции

## Управление

- **WASD / стрелки** — движение (и наводка лодошки!)
- **G / Пробел** — Грибной Залп, **R** — переброс карточек
- **P** — пауза, **M** — звук. Мобилки: палец = джойстик

## Технологии

Чистый JavaScript + Canvas 2D, ноль зависимостей, один `game.js`.
Процедурный звук (WebAudio), вся графика кодом.
Запуск: `node scripts/serve.mjs 3000` → http://localhost:3000
