# Белое Безмолвие — White Silence

> **Русский Север. Зима 1917 года. До весеннего парохода — 60 дней.**

Изометрический 2D-сурвайвл в духе **Project Zomboid**, но вместо зомби — холод, волчьи стаи, медведь-шатун и бандиты-дезертиры. Один персонаж, пермадет, один сейв. «Вот так вы погибли».

**https://genocide12.github.io/white-silence/**

## Об игре

Телеграфист станции **Пристань-Тихая** остаётся один, когда страна рушится и приказы перестают приходить. Полярная ночь наступает на 44-й день. Пароход «Святой Николай» придёт на 60-й — если дождётесь и подадите сигнальный огонь.

Главный враг — не зверь и не человек. Главный враг — **холод**.

### Выживание

| Система | Что делает |
|---|---|
| **Модель температуры** | Ядро тела 37.0°, теплопотеря от ветра/одежды/укрытия/активности, стадии гипотермии до смерти |
| **Нужды** | Голод, жажда, усталость, рассудок — всё истощается и всё убивает |
| **Обморожение** | Пальцы чернеют, точность падает, гангрена при запущенности |
| **Здоровье** | Раны, кровотечения, переломы, инфекции, болезни, боли, опьянение |
| **Погода** | Оттепели, метели, лютые морозы, изморозь, лунные ночи, полярная ночь |
| **Время** | 60 игровых дней; сон ускоряет; до парохода считаются сутки |

### Мир

- **Посёлок на 34 здания**: избы, церковь, лавка, вокзал, трактир, кузница, пилорама, доктор, школа, кладбище — каждое с интерьером, мебелью и лутом.
- **Северный лес**: ели, берёзы, чага, мороженая брусника, следы зверя.
- **Река с лдом**: полыньи, трещины, вмёрзшие лодки, пристань.
- **Живой мир**: олени, зайцы, вороны, лисицы, совы, глухари, бобры — со своими маршрутами.

### Угрозы

- **Волчьи стаи** — ночная осада, окружение, страх огня, вожак на поздних днях.
- **Медведь-шатун** — босс, 260 HP, рёв перед атакой, ломает баррикады.
- **Бандиты-дезертиры** — лагеря, патрули, стрелки и ближники, атаман.
- **Зима как она есть** — мороз до −48, метель с whiteout, гололёд.

### Прогрессия

- **12 навыков** с XP: топор, бой, стрельба, скрытность, бег, готовка, столярка, кройка, медицина, собирательство, следопытство, выживание.
- **447 предметов**: еда (свежесть!), одежда 1917 слоями, инструменты, оружие, медикаменты, документы.
- **243+ рецептов**: готовка (щи, каша, пельмени, медовик), столярка, кройка, боеприпасы.
- **Строительство**: баррикады, снежные стены, капканы, верша в проруби.
- **Охота и рыбалка**: следы, приманки, манок, проруби, разделка.
- **Собирательство**: чага, хвоя, брусника, коренья, поиск под снегом.

### Сюжет

- **3 акта**: обустройство → сжатие → полярная ночь.
- **105+ записок** жителей: дневник охотника Тимофеича, тетрадь фельдшера, письма.
- **Радио 1917**: сводки, цены, морзе, SOS, рождественский перезвон.
- **NPC**: отшельник Аким, конюх Семён, травница Матрёна, беглый солдат Фёдор.
- **Квесты**: мальчик Ванятка, ружьё Тимофеича, волчий вожак, схрон егеря.
- **8 концовок**: пароход, зимовка, схимник, атаман, семья, волчий царь...

### Атмосфера

- Процедурный пиксель-арт: 300+ спрайтов, нарисованных кодом.
- Синтезированный звук: 100+ эффектов Web Audio без единого файла.
- Генеративная музыка: 8 тем (от вальса меню до реквиема).
- Северное сияние, пар дыхания на морозе, скрип снега, вороньи круги.

## Технологии

**Ноль зависимостей.** Никаких CDN, сборщиков, фреймворков — только `<script>` и Canvas 2D:

- ES5-совместимый код, глобальный неймспейс `WS` (без модулей).
- Детерминированная генерация мира из seed (mulberry32 + value noise).
- Изометрия 2:1 с чанковым кэшем рендера и spatial-хэшем.
- Web Audio API: синтез всех звуков кодом, генеративная музыка.
- localStorage: один сейв-слот, пермадет при смерти.

## Структура проекта

```
js/
  core/       ядро: неймспейс, цикл, время, ввод, камера, рендер, спрайты,
              аудио, музыка, сохранение, события
  data/       предметы (еда, одежда, инструменты, блюда), рецепты, таблицы лута
  world/      генерация (рельеф, посёлок, интерьеры), погода, амбиент
  systems/    нужды, температура, огонь, здоровье, инвентарь, крафт, бой,
              навыки, строительство, охота, рыбалка, собирательство,
              лут, диалоги, достижения, статистика
  ai/         волки, медведь, бандиты, животные, отшельник, странники
  entities/   игрок, действия, спрайты (игрок, звери, живность)
  ui/         меню, HUD, инвентарь, крафт, карта, здоровье, навыки, журнал,
              контейнеры, смерть, справка, туториал
  content/    сюжет (3 акта), записки ×105, радио, квесты, концовки,
              эпитафии, святки, лор
  i18n/       RU + EN локализация
css/          базовые стили + каждый экран отдельно
scripts/      build.py — сборка index.html, подсчёт строк
```

## Разработка

```bash
# локальный запуск
python3 -m http.server 8901
open http://localhost:8901

# пересборка index.html после добавления файлов
python3 scripts/build.py
```

Порядок загрузки скриптов: `core → data → world → systems → ai → entities → ui → content → i18n → main`.

## Терминология проекта

- **PZ-style** — в духе Project Zomboid: пермадет, симуляция нужд, «Вот так вы погибли».
- **Шатун** — медведь, не залёгший в спячку; голоден и свиреп.
- **Полынья** — незамёрзшее окно в речном льду; рыбацкое место и опасность.
- **Святки** — дни 35–42 по старому стилю: колядки, гадания, крещенский мороз.
