# Безумный Дед: Грибной Приход 🍄

Bullet-heaven про деда-грибника. Полная переделка с нуля (v2):
старый сурвайвл (110 тыс. строк) заменён компактной аркадой в духе
**Vampire Survivors / Brotato**, построенной на проверенных принципах
жанра: одно управление, оружие бьёт само, награда каждые ~30 секунд.

## Забег

15 минут. Дед ходит по зимнему лесу, мультяшки лезут со всех сторон,
оружие (лодошка, тапок-бумеранг, косяк-веер, кот Барсик, грибная аура,
вантуз) бьёт **само**. Грибы = опыт → уровень → выбор из 3 карточек.
Скрытые **эволюции**: макс. оружие + макс. пассивка-пара = сверхоружие.

- **4:00 / 8:00 / 12:00** — боссы (Альфа-Волк, Медведь-Шиша, Главарь)
- **15:00** — прилетает ТАРЕЛКА: добеги до луча = победа
- **Приход 🍄** (шкала) заполняется грибами → **[G] Грибной Залп**:
  5 секунд радужного безумия с уроном по всему экрану
- 👑 Элиты оставляют **подарки** (слот-машина наград)

## Управление

- **WASD / стрелки** — движение (всё!)
- **G / Пробел** — Грибной Залп (когда приход 100%)
- **P / Esc** — пауза, **M** — звук
- Мобилки: палец по экрану = джойстик

## Технологии

Чистый JavaScript + Canvas 2D, **ноль зависимостей**, один `game.js`.
Процедурный звук (WebAudio-синтез), вся графика рисуется кодом.
Запуск: `node scripts/serve.mjs 3000` → http://localhost:3000

Деплой: статика на GitHub Pages (ветка main).
