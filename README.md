# Белая Тишина: Топка — полярная инкременталка

> **Русский Север. 1917 год. Полярная ночь. До парохода — вся зима, и каждая щепка на счету.**

Браузерная инкременталка (incremental / idle): руби дрова, разжигай топку, разворачивай индустрию тепла —
от ржавого топора до орбитальной лесопилки и чисел вида `1e100`. Автор игры — **DirtyG**.

**Играть: https://genocide12.github.io/white-silence/**

## Что внутри (жанровые свойства — по канону)

- **Числа растут вверх** — экспоненциальная кривая добычи: щепка → миллиард → гугол.
- **Unfolding (раскрытие механик)** — стартуешь с топора; угольная шахта открывается на 25K дров,
  телеграф на 20M, экспедиции на 100M за забег. Каждая система появляется, когда готова.
- **Задачи на оптимизацию** — покупки ×1/×10/MAX, улучшения с условиями, престиж-петля со звёздами.
- **Казуальность** — автоклик, автоартель (автопокупка), оффлайн-доход до 12 часов, сейв в браузере.

### Игровые системы

| Система | Открывается | Зачем |
| --- | --- | --- |
| Артель (10 генераторов) | сразу | экспонента добычи дров |
| Улучшения (24 штуки) | по ходу | ×2 линиям, доля добычи на клик |
| Шахта + Топка | 25K дров всего | уголь → вечный множитель к добыче |
| Телеграф + Изобретения | 20M дров всего | депеши → перманентные перки (переживают престиж) |
| Экспедиция (престиж) | 100M за забег | полярные звёзды: +4% каждая навсегда |
| Звёздный магазин | после 1-й экспедиции | мета-прокачка вплоть до «Парохода» ×10 |
| Подвиги (36 достижений) | по ходу | каждое +1% к производству |
| Северное сияние | ~5 минут игры | ×5 ко всему на 30 секунд, лови момент |

## Технологии

- **Next.js 16** (App Router) + **TypeScript** + **Tailwind CSS 4** + shadcn/ui
- **Чистый игровой движок** в `src/game/` — без React, работает и в браузере, и в тестах, и в симуляторе
- **57 тестов** (`bun test tests/game/`) на формулы, покупки, престиж, оффлайн, сейвы
- **Симулятор роя ботов** (`scripts/sim-incremental.ts`) — 6 стратегий проживают неделю игры
  на скорости 50 000×+, баланс проверен числами, а не на глаз

## Разработка

```bash
bun install
bun run dev        # http://localhost:3000
bun test tests/game/
bun run lint

# статическая сборка для GitHub Pages (в out/)
GITHUB_PAGES=1 bunx next build
```

Деплой: ветка `gh-pages` содержит статическую сборку, GitHub Pages раздаёт её на
`genocide12.github.io/white-silence/`.

## Структура

```
legacy/              — предыдущая игра «Белое Безмолвие»
```
